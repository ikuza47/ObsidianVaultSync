
# Что такое LU-разложение?

LU-разложение - это представление матрицы **A** в виде произведения двух матриц:

`A = L × U`, где:
- **L** - нижняя треугольная матрица (все элементы **выше** главной диагонали равны 0)
- **U** - верхняя треугольная матрица (все элементы **ниже** главной диагонали равны 0)

Пример:
```
          | l₀₀   0    0   |       |  1   u₀₁  u₀₂ |
A = L×U = | l₁₀  l₁₁   0   |   ×   |  0    1   u₁₂ |
          | l₂₀  l₂₁  l₂₂  |       |  0    0    1  |
```

#### Зачем это нужно?

Решение системы `A × x = b` сводится к двум более простым шагам:

1. `L × y = b` - прямой ход (находим промежуточный вектор y)
2. `U × x = y` - обратный ход (находим искомый вектор x)

---
## Как решать по этому методу?
1. Приводим матрицу A к треугольному виду (т.к. у нас диагональ U единичная, мы делаем по нижнему треугольнику) 
	Матрица которая у нас должна выйти:
```
     | l₀₀   0    0   | 
A => | l₁₀  l₁₁   0   | 
     | l₂₀  l₂₁  l₂₂  | 
```
2. После получения треугольной матрицы мы ищем матрицу U. Изначально можем сразу по диагонали поставить 1, а ниже диагонали 0
```
|  1    ?    ?  |
|  0    1    ?  |
|  0    0    1  |
```
3. Узнать оставшиеся элементы можно воспользовавшись числами, на которые мы делили строки матрицы A чтобы получить матрицу L. [^1]
	Так же можно делить матрицу A на матрицу L и по итогу мы получим матрицу U
4. После того как мы получили обе матрицы (LU) мы находим промежуточный вектор y **Ly=b** прямым ходом. Поначалу мы найдём y1, т.к. у нас в 1 строке только 1 не нулевой элемент и т.д.
```
| l₀₀   0    0   |   |y₀|   |b₀|
| l₁₀  l₁₁   0   | × |y₁| = |b₁|
| l₂₀  l₂₁  l₂₂  |   |y₂|   |b₂|
```
3. После того как нашли вектор *y* находим вектор *x*, который будет ответом **Ux=y**. Он уже будет находится обратным ходом.
```
| 1   l₁₀   l₂₀  |   |x₀|   |y₀|
| 0    1    l₂₁  | × |x₁| = |y₁|
| 0    0     1   |   |x₂|   |y₂|
```
---
  
## Формулы для решения этим методом

> [!info] 
> Эти формулы используются в коде, поэтому в итоге я пишу их примерно так 
> `A[i][j] = Σ(L[i][k] × U[k][j])`

### Откуда берётся формула для L?
Нам нужно, чтобы выполнялось равенство `A = L × U`

По правилу умножения матриц:

`A[i][j] = Σ(L[i][k] × U[k][j])`, где k от 0 до n-1

Для диагонального элемента A:

`A[i][i] = L[i][0]×U[0][i] + L[i][1]×U[1][i] + ... + L[i][i]×U[i][i] + ...`

  
Учитываем свойства треугольных матриц:
1. **U (ki)= 0 при k > i** (ниже диагонали в U стоят нули)
2. **L (ik) = 0 при k > i** (выше диагонали в L стоят нули)
3. **U (ii) = 1** (единичная диагональ)

Поэтому сумма упрощается:

`A[i][i] = Σ(L[i][k] × U[k][i]) + L[i][i]`, где k от 0 до i-1

**Выражаем L *(ii)*:**

`L[i][i] = A[i][i] - Σ(L[i][k] × U[k][i])`, где k от 0 до i-1

  

#### Почему мы перемножаем и вычитаем, чтобы найти L по диагонали?

когда мы перемножаем L и U, диагональный элемент `A[i][i]` получается не только из `L[i][i]`, но и из произведения других элементов.
Поэтому чтобы найти `L[i][i]`, мы:
1. Считаем вклад всех **уже известных** элементов (`sum`)
2. Вычитаем этот вклад из `A[i][i]`
3. Остаток - это и есть `L[i][i]`

### Откуда берётся формула для U?
Рассмотрим элемент `A[i][j]` где `j > i` (элемент выше диагонали).

По правилу умножения матриц:

`A[i][j] = Σ(L[i][k] × U[k][j]), где k от 0 до n-1`

Разбиваем сумму на части:

`A[i][j] = L[i][0]×U[0][j] + L[i][1]×U[1][j] + ... + L[i][i]×U[i][j] + ... + L[i][n-1]×U[n-1][j]`

Учитываем свойства:
1. **U *(kj)* = 0 при k > j** (в U ниже диагонали нули)
2. **L *(ik)* = 0 при k > i** (в L правее диагонали нули)
3. Нас интересует случай **j > i**, поэтому сумма обрывается на k = i:

`A[i][j] = Σ(L[i][k] × U[k][j]) + L[i][i]×U[i][j], где k от 0 до i-1`

**Выражаем U *(ij)*:**

`L[i][i] × U[i][j] = A[i][j] - Σ(L[i][k] × U[k][j]), где k от 0 до i-1`

`U[i][j] = (A[i][j] - Σ(L[i][k] × U[k][j])) / L[i][i]`

## Алгоритм кода

> [!warning] Примерный алгоритм

 
1. Ввод данных 
	1. Размерность матрицы
	2. Матрица
	3. Вектор
2. Инициализация (Чтобы не возникало никаких ошибок, матрицам L U установим все элементы 0)
3. Основные действия
	1. LU-разложение (цикл)
		1. Вычисляем L *(ii)* *Тут же проверяем на вырожденность, если находим - выводим в консоль, что матрица вырождена*
		2. Находим U *(ij)* *(Обязательно j>i)*
			1. U *(ii)* = 1
			2. Сумма* (sum)* = `Σ(L[i][k] × U[k][j])`, где к от 0 до i-1
			3. U *(ij)*  = ( A *(ij)* - sum ) / L *(ii)*
		3. Находим L *(ji)* *(Обязательно j>i)* 
			1. Сумма = `Σ(L[j][k] × U[k][i])`, где k от 0 до i-1
			2. L *(ji) *= (A* (ji)* - sum) / U* (ii)*
	2. Находим y
		1. Прямой ход `L×y  = b`
	3. Находим x
		1. Обратный ход `U×x  = y`

*3.1.2 - 3.1.3* - Поначалу находим элемент в матрице U, после чего находим в матрице L (в U строка, в L столбец)

---
 Основным различием между тем как решает человек и как решает алгоритм по сути является только пункт 3.1.  Когда решает человек, он изначально находит всю матрицу L (либо U), и только потом приступает к другой, алгоритм же находит элемент L по диагонали *(ii)*, потом находит элементы U *(ij)*, после чего благодаря этим элементам находит элементы L *(ji)* и так пока не получится законченные треугольные матрицы. 
 В остальном алгоритм и человек решают идентично - точно такой же прямой и обратный ход.
